## Anti-padrões

| Anti-padrão                                  | Por quê                     |
| -------------------------------------------- | --------------------------- |
| Card grid storytelling no prospecto pastoral | Contamina Direção A         |
| Hero com stats/chips/overlays                | Viola orçamento de abertura |
| Umbral “dark mode” genérico                  | PAD-03 é único e narrativo  |
| Div clicável sem botão/link                  | Quebra teclado/a11y         |
| Inventar callout com copy pastoral           | Copy só em `conteudo/`      |
