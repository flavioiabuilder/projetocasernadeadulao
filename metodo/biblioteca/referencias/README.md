# Biblioteca de referências (índice)

Esta pasta guarda **fichas leves** (metadados, anotações, links). Não duplica
reconstruções, capturas pesadas nem ativos de
[`../../../referencias-devtools/`](../../../referencias-devtools/).

## Diferença de papéis

| Área                             | Papel                                                                 |
| -------------------------------- | --------------------------------------------------------------------- |
| `referencias-devtools/`          | Estudos técnicos, evidências, reconstruções independentes             |
| `metodo/biblioteca/referencias/` | Taxonomia e anotações para o método (estrutura / atmosfera / detalhe) |

## Política

- Só metadados + links internos/externos
- Distinguir evidência de inferência
- Declarar limites e licença
- Não publicar esta pasta no GitHub Pages (já fora do workflow)
- Não redistribuir ativos proprietários

## Taxonomia sugerida

- **Setor** (ex.: energia, educação, pastoral, e-commerce)
- **Eixo:** `estrutura` | `atmosfera` | `detalhe`
- **Tipo:** DevTools | produto | concorrência | tipografia | motion

## Como adicionar

1. Copie [`_ficha-modelo.md`](_ficha-modelo.md) para `entradas/<slug>.md`
2. Preencha todos os campos
3. Linke a evidência existente (DevTools, docs do programa, URL)
4. Não copie a pasta `auditoria/` ou `design-system/` para cá
